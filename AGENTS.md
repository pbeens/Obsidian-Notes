# Project Instructions

This repository contains a distributable ChatGPT Skill.

The objective is to maintain the Skill and produce a valid `skill.zip` that users can download and upload to ChatGPT.

## Session Startup

At the beginning of each session:

1. Read `tasks.md`.
2. Inspect the repository.
3. Review relevant source files.
4. Identify the current project phase.
5. Continue with the next available task.

## Source Files

`source/instructions.md` contains the user's supplied instructions.

`source/references/` contains optional supporting materials.

`skill/obsidian-notes/SKILL.md` is the final Skill implementation.

## Task Management

Update `tasks.md` after meaningful work. Preserve completed tasks and user notes. Do not repeat completed initialization work.

## Development

Preserve the user's intended behavior. Prefer the simplest working implementation. Do not create unnecessary plugin infrastructure. Validate generated packages.

## Publication

Do not commit secrets or confidential material. Do not push or publish without authorization.
